# Crop Disease & Quality Analysis

End-to-end system combining:
- **Computer Vision**: EfficientNet-B0 transfer learning on leaf images (PlantVillage) for disease classification, with Grad-CAM explainability
- **Tabular ML**: XGBoost (Optuna-tuned) on soil/nutrient data for quality scoring, with SHAP explainability
- **Fusion**: Stacked meta-learner combining both branches, with a "needs review" flag when the two branches disagree
- **Backend**: FastAPI, SQLite logging of predictions
- **Frontend**: Plain HTML/CSS/JS (Jinja2 templates, Chart.js) — upload page + results + history dashboard

No authentication — open access, intended for local/demo use.

## Setup (Windows PowerShell)

```powershell
# 1. Create and activate virtual environment
python -m venv venv
.\venv\Scripts\Activate.ps1

# If activation is blocked:
# Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 2. Install dependencies
python -m pip install --upgrade pip
pip install -r requirements.txt

# If you have an NVIDIA GPU, install the CUDA build of torch instead:
# pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

## Get the datasets

```powershell
# Kaggle API token required: kaggle.com/settings -> API -> Create New Token
mkdir $env:USERPROFILE\.kaggle
copy kaggle.json $env:USERPROFILE\.kaggle\kaggle.json

# Image dataset (PlantVillage)
kaggle datasets download -d abdallahalidev/plantvillage-dataset -p data\plantvillage --unzip

# Tabular dataset (Crop Recommendation)
kaggle datasets download -d atharvaingle/crop-recommendation-dataset -p data\tabular --unzip
```

## Training pipeline (run in order, from `src/`)

```powershell
cd src

# 1. Image model (EfficientNet-B0 transfer learning)
python train.py
python evaluate.py
python gradcam.py

# 2. Tabular model (XGBoost + Optuna)
python tabular_data.py
python tabular_train.py
python tabular_shap.py

# 3. Fusion model (stacked meta-learner on synthetic paired samples)
python fusion_pairing.py
python fusion_train.py
```

## Run the app

```powershell
cd api
uvicorn main:app --reload
```

## Notes / limitations to mention in your report

- The fusion model is trained on **synthetically paired** image+tabular samples (see `fusion_pairing.py`) since the two source datasets aren't naturally linked — this is a stated, documented assumption, not a hidden shortcoming.
- The tabular "quality score" reframes the Crop Recommendation dataset (originally built for crop suggestion) using deviation from agronomic ideal ranges — a deliberate feature-engineering contribution.
- No authentication layer — add one (e.g. FastAPI + OAuth2/JWT) before any real deployment.
